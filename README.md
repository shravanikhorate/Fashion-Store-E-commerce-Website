Fashion Store E-Commerce Website

This is a React-based Fashion Store UI project created for Assignment 1.

Features

- Responsive Navbar
- Hero Section
- Categories Section
- Product Cards
- Testimonials
- Footer
- Multiple Pages using React Router

Technologies Used

- React JS
- CSS
- React Router DOM
- Vite
